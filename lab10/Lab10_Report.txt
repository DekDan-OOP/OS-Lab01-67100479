2. Hardware Utilization:

Answer: The OS successfully ran Workload A, Workload B, and Workload C at the same time because each workload required different resources. Workload A used 40 GB of RAM and GPUs 0, 1, and 2 for LLaMA training. Workload B required 16 GB of RAM but no GPU, so it could run on the CPU and perform data preprocessing while Workload A was using the GPUs. Workload C required only 2 GB of RAM and GPU 3, which was still available. Therefore, all four GPUs and most of the available RAM could be utilized without the workloads blocking each other. The OS used locks and resource checking to prevent two jobs from using the same resource at the same time.
